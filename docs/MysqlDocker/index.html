Antes de começar: cliente e servidor

Uma base de dados funciona segundo uma arquitetura cliente–servidor. O servidor guarda os dados, executa SQL e responde aos pedidos. Um cliente liga-se ao servidor para enviar esses pedidos e apresentar os resultados.

ComponentePapel neste DockerQuem o chama
MySQLÉ o servidor da base de dados. Corre no contentor chamado mysql, recebe pedidos e guarda os dados no volume mysql_dados.É chamado pelo phpMyAdmin ou pelo programa mysql usado no terminal.
phpMyAdminÉ um cliente web. Mostra páginas e formulários no browser, mas envia ao servidor MySQL as operações que pedimos.O browser chama o phpMyAdmin em http://localhost:8081. O phpMyAdmin chama o servidor através do nome mysql.
Programa mysqlÉ um cliente de linha de comando. Permite escrever SQL sem usar o browser.É iniciado pelo utilizador no PowerShell ou Terminal e liga-se ao servidor MySQL.
Dois significados de “mysql”: em docker compose exec mysql mysql ..., o primeiro mysql identifica o contentor e o segundo inicia o programa cliente dentro desse contentor.

3. Preparar e arrancar

Abrir PowerShell na pasta

  1. Abra MysqlDocker no Explorador.
  2. Clique na barra do caminho.
  3. Escreva powershell e carregue Enter.
Copy-Item .env.example .env

Abrir Terminal na pasta

  1. No Finder, clique na pasta MysqlDocker com o botão direito.
  2. Escolha Serviços → Novo Terminal na Pasta.
cp .env.example .env

O ficheiro .env contém a base, utilizadores, senhas e portas:

MYSQL_ROOT_PASSWORD=rootpass
MYSQL_DATABASE=escola
MYSQL_USER=aluno
MYSQL_PASSWORD=alunopass
MYSQL_PORT=3306
PHPMYADMIN_PORT=8081
São valores simples para aprendizagem local. Não reutilize estas senhas num servidor real.

Arrancar

docker compose -f MysqlDocker.yml up -d

Na primeira vez, o download pode demorar alguns minutos.

Confirmar

docker compose -f MysqlDocker.yml ps

MySQL deve aparecer como healthy.

Porta 3306 ocupada? Mude para MYSQL_PORT=3307 no .env e repita up -d.

5. Criar uma base e uma tabela manualmente

  1. Abra http://localhost:8081 e entre como root.
  2. Clique em Novo, na coluna esquerda.
  3. Em Nome da base de dados, escreva redesocial.
  4. Escolha uma ordenação utf8mb4, por exemplo utf8mb4_0900_ai_ci, e clique em Criar.
  5. Selecione a base redesocial. Na zona Criar tabela, escreva utilizador, indique 4 colunas e avance.

Definir as colunas

NomeTipoComprimentoNulo?Índice
utilizadoridINTdeixe vazioNãoPRIMARY
emailutilizadorVARCHAR100Sim—
nomeutilizadorVARCHAR100Sim—
paisresidenciaVARCHAR50Sim—

No fim, clique em Guardar. A chave primária identifica cada linha sem ambiguidades. Dois utilizadores não podem ter o mesmo utilizadorid.

Inserir, consultar e alterar dados

  • Inserir: abra a tabela, escolha Inserir, preencha os valores e execute.
  • Consultar: escolha Visualizar.
  • Alterar: em Visualizar, clique em Editar junto da linha.
  • Alterar a estrutura: escolha Estrutura e use Alterar junto da coluna.

Criar uma chave estrangeira

  1. Crie primeiro as duas tabelas (utilizadores e post) e as respetivas chaves primárias. Ambas devem usar o motor InnoDB.
  2. Na tabela que vai guardar a chave estrangeira (post), abra Estrutura.
  3. Escolha Vista de relações, normalmente no fundo da página ou no menu Mais.
  4. Escolha a coluna local, a tabela referenciada e a coluna referenciada.
  5. Escolha com cuidado as ações ON DELETE e ON UPDATE, depois guarde.
Se “Vista de relações” não aparecer: confirme que a tabela usa InnoDB, que as colunas relacionadas têm tipos compatíveis e que a coluna referenciada tem um índice PRIMARY ou UNIQUE.

6. MySQL na linha de comando

Entrar diretamente no cliente MySQL

docker compose -f MysqlDocker.yml exec mysql mysql -u aluno -p escola

Quando pedir a senha, escreva-a. Nada aparece enquanto escreve; é normal.

SHOW TABLES;
SELECT * FROM aluno;
SELECT nome, curso FROM aluno ORDER BY nome;
EXIT;

Entrar como root

docker compose -f MysqlDocker.yml exec mysql mysql -u root -p

Abrir primeiro o terminal Linux do contentor

docker compose -f MysqlDocker.yml exec mysql bash
mysql -u aluno -p escola
EXIT;
exit

EXIT; sai do MySQL; exit sai do terminal do contentor.

7. Executar um script SQL

O exemplo exemplos/mais_alunos.sql está visível dentro do contentor em /exemplos/mais_alunos.sql.

Executar a partir do PowerShell ou Terminal

docker compose -f MysqlDocker.yml exec mysql sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE" < /exemplos/mais_alunos.sql'
Onde estão o utilizador, a senha e a base de dados? $MYSQL_USER, $MYSQL_PASSWORD e $MYSQL_DATABASE são variáveis existentes dentro do contentor. Recebem automaticamente os valores definidos no ficheiro .env. Por exemplo, com MYSQL_USER=aluno, MYSQL_PASSWORD=alunopass e MYSQL_DATABASE=escola, a parte interna equivale a mysql -ualuno -palunopass escola < /exemplos/mais_alunos.sql. Usar as variáveis evita escrever a senha diretamente no comando.

Se já estiver dentro do MySQL

Quando vê o prompt mysql>, não volte a escrever o comando mysql. Execute o ficheiro com SOURCE:

USE escola;
SOURCE /exemplos/mais_alunos.sql;
SELECT * FROM aluno ORDER BY numero;

O ponto e vírgula no fim de cada instrução é obrigatório. SOURCE lê e executa todas as instruções existentes no ficheiro.

Se estiver no terminal Linux do contentor

Se o ecrã mostrar algo semelhante a bash-5.1#, ainda não está dentro do MySQL. Entre primeiro:

mysql -u aluno -p escola

Escreva a senha quando for pedida e depois use SOURCE /exemplos/mais_alunos.sql;.

Confirmar a partir do PowerShell ou Terminal

docker compose -f MysqlDocker.yml exec mysql mysql -u aluno -p escola -e "SELECT * FROM aluno ORDER BY numero;"
Importar pelo phpMyAdmin

Entre na base escola, abra Importar, selecione o ficheiro SQL e confirme.

Inicialização: os ficheiros de inicializacao/ correm automaticamente apenas quando o volume é criado vazio. Alterá-los depois não modifica uma base existente.

8. Exemplo completo: rede social

Foram acrescentados dois scripts. O primeiro cria seis tabelas, respetivas chaves primárias e chaves estrangeiras. O segundo introduz dados de exemplo.

Descarregar redesocial_tabelas.sqlDescarregar redesocial_dados.sql

No phpMyAdmin

  1. Entre como root e crie uma base chamada redesocial.
  2. Selecione essa base na coluna esquerda.
  3. Abra Importar, escolha redesocial_tabelas.sql e execute.
  4. Quando terminar sem erros, importe redesocial_dados.sql.
  5. Abra Estrutura para ver as tabelas ou Visualizar para consultar os dados.

Já dentro do MySQL

CREATE DATABASE IF NOT EXISTS redesocial
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
USE redesocial;
SOURCE /exemplos/redesocial_tabelas.sql;
SOURCE /exemplos/redesocial_dados.sql;
SHOW TABLES;
SELECT * FROM utilizador;
A ordem é importante: execute primeiro o ficheiro das tabelas e só depois o ficheiro dos dados. O script das tabelas elimina as tabelas com os mesmos nomes antes de as voltar a criar.

9. Importar um CSV

numero,nome,curso,email
100003,Carla Martins,LEI,carla.martins@example.test
100004,Diogo Santos,LIGE,diogo.santos@example.test

Pelo phpMyAdmin

  1. Abra a base escola e a tabela aluno.
  2. Escolha Importar e selecione exemplos/alunos.csv.
  3. Escolha CSV, separador vírgula e UTF-8.
  4. Indique que a primeira linha contém nomes das colunas, se surgir essa opção.
  5. Confirme.

Pela linha de comando

docker compose -f MysqlDocker.yml exec mysql mysql --local-infile=1 -u aluno -p escola

Dentro de mysql> execute:

LOAD DATA LOCAL INFILE '/exemplos/alunos.csv'
INTO TABLE aluno
CHARACTER SET utf8mb4
FIELDS TERMINATED BY ','
OPTIONALLY ENCLOSED BY '"'
LINES TERMINATED BY '\n'
IGNORE 1 LINES
(numero, nome, curso, email);

SELECT * FROM aluno ORDER BY numero;
Repetir os mesmos números produz um erro de chave duplicada. A chave primária está a proteger os registos.

10. Exportar para CSV e SQL

CSV

Apague primeiro um ficheiro anterior com o mesmo nome:

docker compose -f MysqlDocker.yml exec mysql rm -f /var/lib/mysql-files/alunos.csv

Crie o CSV:

docker compose -f MysqlDocker.yml exec mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" escola -e "SELECT numero,nome,curso,email FROM aluno ORDER BY numero INTO OUTFILE '\''/var/lib/mysql-files/alunos.csv'\'' CHARACTER SET utf8mb4 FIELDS TERMINATED BY '\'','\'' OPTIONALLY ENCLOSED BY '\''\"'\'' LINES TERMINATED BY '\''\n'\'';"'

O resultado fica em exportacoes/alunos.csv. Não inclui cabeçalho.

Script SQL completo

docker compose -f MysqlDocker.yml exec mysql sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" --routines --triggers --events --databases escola > /var/lib/mysql-files/escola_backup.sql'

O resultado fica em exportacoes/escola_backup.sql.

Restaurar o script

docker compose -f MysqlDocker.yml exec mysql sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" < /var/lib/mysql-files/escola_backup.sql'
Cuidado: restaurar pode substituir estruturas e dados. Faça primeiro um backup do estado atual.
Exportar pelo phpMyAdmin

Selecione a base escola, abra Exportar e escolha SQL. Para CSV, selecione a tabela ou o resultado de uma consulta e use a exportação correspondente.

12. Problemas frequentes

Cannot connect to the Docker daemon

Abra Docker Desktop e espere que fique pronto.

Port is already allocated

Mude MYSQL_PORT=3307 no .env.

Access denied

Confirme utilizador e senha. Alterar o .env depois da primeira execução não altera automaticamente uma senha que já está na base.

O script inicial não voltou a correr

É normal. Só corre num volume vazio. Execute-o manualmente ou use conscientemente down -v.

Acentos errados no Excel

Importe o CSV indicando UTF-8 e vírgula como separador.

Verificação final

  • Docker Desktop está aberto.
  • Existe um ficheiro chamado exatamente .env.
  • Está dentro da pasta MysqlDocker.
  • Usou -f MysqlDocker.yml.
  • MySQL aparece saudável.
  • phpMyAdmin abre em http://localhost:8081.
  • Antes de usar down -v, confirmou que pode apagar os dados.
