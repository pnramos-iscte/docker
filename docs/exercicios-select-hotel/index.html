Verificação: A condição de sobreposição pode ser escrita de forma mais curta e geral: entrada antes do fim do intervalo e saída no início ou depois.

SELECT DISTINCT h.designacao
FROM hotel AS h
JOIN reserva_quartos AS rq ON rq.sigla_hotel = h.sigla_hotel
JOIN reserva AS r ON r.numero_reserva = rq.numero_reserva
WHERE r.dia_entrada < '2012-10-01'
  AND r.dia_saida >= '2012-08-01'
ORDER BY h.designacao;

Verificação: COUNT(DISTINCT ...) é necessário porque uma reserva pode conter mais do que um quarto.

SELECT h.designacao,
       COUNT(DISTINCT f.numero_factura) AS total_facturas
FROM hotel AS h
LEFT JOIN reserva_quartos AS rq ON rq.sigla_hotel = h.sigla_hotel
LEFT JOIN factura AS f ON f.numero_reserva = rq.numero_reserva
GROUP BY h.sigla_hotel, h.designacao
ORDER BY h.designacao;

WITH numero_quartos AS (
  SELECT h.sigla_hotel, h.designacao,
         COUNT(q.numero_quarto) AS total_quartos
  FROM hotel AS h
  LEFT JOIN quarto AS q ON q.sigla_hotel = h.sigla_hotel

Verificação: O resultado contém 42 linhas. A matriz apresenta as mesmas linhas de forma compacta. A contagem usa DISTINCT porque uma reserva pode ocupar vários quartos.

SELECT c.nome_cliente, h.sigla_hotel,
       (SELECT COUNT(DISTINCT r.numero_reserva)
        FROM reserva AS r
        JOIN reserva_quartos AS rq ON rq.numero_reserva = r.numero_reserva
        WHERE r.numero_cliente = c.numero_cliente
          AND rq.sigla_hotel = h.sigla_hotel) AS total
FROM cliente AS c
JOIN organizacao AS o ON o.numero_cliente = c.numero_cliente
CROSS JOIN hotel AS h
ORDER BY c.numero_cliente, h.sigla_hotel;
17

Listar os hotéis com o maior número de quartos livres, considerando livre um quarto que nunca aparece em Reserva_Quartos.

Resultado esperado

designacao | total_livres
Mundial    | 8
Sheraton   | 8

Verificação: Com os dados fornecidos, “livre” significa nunca reservado, não livre numa data concreta.

WITH quartos_livres AS (
  SELECT h.sigla_hotel, h.designacao,
         COUNT(q.numero_quarto) AS total_livres
  FROM hotel AS h
  LEFT JOIN quarto AS q
    ON q.sigla_hotel = h.sigla_hotel
   AND NOT EXISTS (
     SELECT 1 FROM reserva_quartos AS rq
     WHERE rq.sigla_hotel = q.sigla_hotel
       AND rq.numero_quarto = q.numero_quarto
   )
  GROUP BY h.sigla_hotel, h.designacao
)
SELECT designacao, total_livres
FROM quartos_livres
WHERE total_livres = (SELECT MAX(total_livres) FROM quartos_livres);

Listar as organizações que têm reservas em todos os hotéis com quartos. O hotel Baia fica excluído porque não tem quartos.

Resultado esperado

nome_cliente
ONU

Verificação: A dupla negação traduz “não existe um hotel com quartos no qual a organização não tenha reservado”.

SELECT c.nome_cliente
FROM cliente AS c
JOIN organizacao AS o ON o.numero_cliente = c.numero_cliente
WHERE NOT EXISTS (
  SELECT 1
  FROM hotel AS h
  WHERE EXISTS (SELECT 1 FROM quarto AS q WHERE q.sigla_hotel = h.sigla_hotel)
    AND NOT EXISTS (
      SELECT 1
      FROM reserva AS r
      JOIN reserva_quartos AS rq ON rq.numero_reserva = r.numero_reserva
      WHERE r.numero_cliente = c.numero_cliente
        AND rq.sigla_hotel = h.sigla_hotel
    )
)
ORDER BY c.nome_cliente;
19

Listar o hotel com maior volume de faturação e indicar o respetivo valor.

Resultado esperado

designacao | total
Roma       | 2000.00

Verificação: A fatura tem de ser deduplicada dentro de cada hotel antes do SUM; uma reserva com dois quartos não pode duplicar o valor.

WITH facturas_hotel AS (
  SELECT DISTINCT h.sigla_hotel, h.designacao,
                  f.numero_factura, f.valor_factura
  FROM hotel AS h
  JOIN reserva_quartos AS rq ON rq.sigla_hotel = h.sigla_hotel
  JOIN factura AS f ON f.numero_reserva = rq.numero_reserva
), totais AS (
  SELECT sigla_hotel, designacao, SUM(valor_factura) AS total
  FROM facturas_hotel
  GROUP BY sigla_hotel, designacao
)
SELECT designacao, total
FROM totais
WHERE total = (SELECT MAX(total) FROM totais);
