Que género fez mais vezes Robert De Niro?

Um campo contém vários géneros separados por vírgulas. Vamos transformá-lo numa lista consultável, contar as obras por género e perceber por que razão duas soluções equivalentes podem demorar 46 segundos ou apenas 0,02 segundos.

Começar ↓Descarregar slides sem respostas
SELECT tconst, primaryTitle, genres
FROM titlebasics
WHERE genres IS NOT NULL
LIMIT 5;

-- Um campo pode conter:
Crime,Drama
Comedy,Drama,Romance
01

Começar no Docker

Antes de executar as consultas, inicie os contentores e abra o cliente MySQL dentro do contentor.

  1. Abra um terminal na pasta onde guardou MysqlDocker.yml.
  2. Inicie os contentores com o comando apresentado abaixo.
  3. No Docker Desktop, abra o contentor do MySQL e escolha o separador Terminal ou a opção representada por ….
  4. No terminal do contentor, execute mysql -u root -p e introduza a palavra-passe definida no ficheiro .env.
# No terminal, dentro da pasta do Docker
docker compose -f MysqlDocker.yml up -d

Porque é necessário indicar -f?

O ficheiro chama-se MysqlDocker.yml. Como não tem o nome habitual compose.yml ou docker-compose.yml, indicamos explicitamente o ficheiro que o Docker deve usar.

# No terminal do contentor MySQL
mysql -u root -p

O que significa?

mysql abre o cliente de linha de comandos; -u root escolhe o utilizador root; -p pede a palavra-passe. Os caracteres da senha não aparecem enquanto escreve — é normal.

USE imdb_key;
SHOW TABLES;

Ativar a base de dados

O exercício pressupõe que a base de dados IMDb já foi importada. USE imdb_key torna-a ativa e SHOW TABLES permite confirmar que existem, entre outras, namebasics, titleprincipals e titlebasics.

Se a sua base de dados tiver outro nome, substitua imdb_key nesse comando pelo nome utilizado na importação.
02

O problema escondido numa coluna

A tabela titlebasics não guarda um género por linha. O campo genres pode conter uma lista de valores separados por vírgulas.

Exemplo simplificado de titlebasics
tconstprimaryTitlegenres
tt0000001Exemplo ADocumentary,Short
tt0000002Exemplo BAnimation,Short
tt0000003Exemplo CAnimation,Comedy,Romance
Uma linha já não corresponde a um único género. Não podemos fazer simplesmente GROUP BY genres, porque isso criaria grupos como Crime,Drama e Drama, tratando-os como valores diferentes.

Antes de escrever SQL

Que etapas seriam necessárias para responder à pergunta? Tente identificar onde está Robert De Niro, onde estão as suas participações e onde estão os géneros das obras.

03

Separar texto com SUBSTRING_INDEX

SUBSTRING_INDEX devolve a parte do texto que fica antes ou depois de um determinado número de separadores.

SELECT SUBSTRING_INDEX(
  'Avenida da Liberdade,12,Lisboa,Portugal',
  ',', 2
);

Contagem positiva

O valor 2 conserva tudo até à segunda parte.

Resultado: Avenida da Liberdade,12.

SELECT SUBSTRING_INDEX(
  'Avenida da Liberdade,12,Lisboa,Portugal',
  ',', -1
);

Contagem negativa

O valor -1 conta a partir do fim e devolve a última parte.

Resultado: Portugal.

Para extrair o segundo género: primeiro conservamos os dois primeiros valores e, desse resultado, retiramos o último.

Extraia o primeiro, o segundo e o terceiro género

Experimente com Animation,Comedy,Romance. O resultado esperado são três colunas: Animation, Comedy e Romance.

Construa a lista de todos os géneros

Crie uma view chamada genre_all, com uma única coluna genre. Use vários SELECT DISTINCT e junte-os com UNION.

05

Conservar apenas o maior total

A consulta anterior produz uma linha por género. Falta selecionar a linha cujo total é igual ao maior total observado.

A ideia de >= ALL: o total de um género tem de ser maior ou igual a todos os totais produzidos pela subconsulta. Se houver um empate no máximo, aparecem todos os géneros empatados.

Qual foi o género mais frequente?

Complete a consulta anterior com HAVING e uma subconsulta que volte a calcular os totais por género.

06

A mesma resposta, tempos muito diferentes

Na medição apresentada na resolução original, a solução com a view demorou cerca de 46 segundos. Ao materializar a lista numa tabela, a consulta demorou cerca de 0,02 segundos.

07

O que a dificuldade revela sobre o modelo

A lista separada por vírgulas obriga o SQL a interpretar texto. Num modelo normalizado, cada associação entre uma obra e um género teria a sua própria linha.

titlebasics
uma linha por obra
1—N
title_genre
uma linha por associação
N—1
genre
uma linha por género

Vantagens

Não é necessário separar strings. As chaves estrangeiras garantem géneros válidos e os índices podem ajudar diretamente nas ligações.

Custo

O modelo passa a ter mais uma tabela e a importação dos dados originais exige transformar a lista em várias linhas.

Questão de reflexão

Se pudesse redesenhar a base de dados, que chaves primárias e estrangeiras usaria em title_genre?

Ideias a conservar

Um campo com uma lista dificulta consultas

GROUP BY genres agruparia combinações, não cada género individual.

Uma view simplifica, mas não materializa

A definição pode voltar a executar operações caras.

A estrutura influencia o desempenho

Uma tabela ou um modelo normalizado permite consultar os valores já separados.
